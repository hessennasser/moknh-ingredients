# moknh-ingredients

Static HTML content fragments for the 70 ingredients in the moknh (مُكنة) blend, used by the "دليل المكونات" page on trymoknh.com. Each fragment is fetched client-side and rendered inside a modal on the store page — these files are not meant to be opened standalone.

Fetch pattern:
`https://raw.githubusercontent.com/hessennasser/moknh-ingredients/main/ingredients/<slug>.html`
